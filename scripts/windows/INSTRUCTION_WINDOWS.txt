============================================================
ชุดคำสั่งสำหรับรันระบบอ่านบัตรประชาชน (Thai ID Card) บน Windows
โครงการ: กฤตหลอมทอง (krit Gold)
============================================================

หากต้องการย้ายระบบไปใช้งานบนเครื่อง Windows ให้ปฏิบัติตามขั้นตอนดังนี้:

ขั้นตอนที่ 1: ติดตั้งโปรแกรมที่จำเป็น
-------------------------------------------
1. ดาวน์โหลดและติดตั้ง Python จาก https://www.python.org
   ** สำคัญ: ตอนติดตั้งให้ติ๊กถูกที่ช่อง "Add Python to PATH" ด้วย **
2. เปิด Command Prompt (กดปุ่ม Windows แล้วพิมพ์ cmd)
3. พิมพ์คำสั่งด้านล่างนี้แล้วกด Enter เพื่อติดตั้ง Library อ่านบัตร:
   pip install pyscard

ขั้นตอนที่ 2: การเตรียมไฟล์
-------------------------------------------
1. คัดลอกโฟลเดอร์ "scripts" ทั้งหมดไปไว้ที่เครื่อง Windows
2. ตรวจสอบว่าในโฟลเดอร์มีไฟล์เหล่านี้อยู่ครบ:
   - bridge.py
   - read_id_card.py
   - windows/run_bridge.bat
   - windows/run_bridge.vbs

ขั้นตอนที่ 3: วิธีการรันระบบ (เลือก 1 วิธี)
-------------------------------------------
วิธีที่ A: รันแบบเห็นสถานะ (เปิดหน้าต่างดำทิ้งไว้)
   - ให้ดับเบิลคลิกที่ไฟล์ "windows/run_bridge.bat"
   - จะมีหน้าต่างขึ้นว่า "Starting Thai ID Bridge on port 8080..." 
   - ห้ามปิดหน้าต่างนี้ขณะใช้งานหน้าเว็บ

วิธีที่ B: รันแบบเบื้องหลัง (ไม่รบกวนหน้าจอ - แนะนำ!)
   - ให้ดับเบิลคลิกที่ไฟล์ "windows/run_bridge.vbs"
   - ระบบจะรันเงียบๆ อยู่เบื้องหลัง ไม่มีหน้าต่างขึ้นมากวนใจ

ขั้นตอนที่ 4: การตั้งค่าให้รันอัตโนมัติเมื่อเปิดเครื่อง
-------------------------------------------
1. กดปุ่ม (Windows + R) บนคีย์บอร์ด
2. พิมพ์คำว่า "shell:startup" แล้วกด Enter
3. หน้าต่างโฟลเดอร์ Startup จะเด้งขึ้นมา
4. ให้สร้าง "Shortcut" ของไฟล์ "run_bridge.vbs" แล้วลากมาวางไว้ในโฟลเดอร์นี้
5. ครั้งต่อไปเมื่อเปิดเครื่อง ระบบจะรันตัวอ่านบัตรให้เองอัตโนมัติทันที

การทดสอบ:
-------------------------------------------
เปิด Browser ไปที่หน้าเว็บระบบคำนวณบิล และลองกดปุ่ม "อ่านบัตรประชาชน" 
หากระบบทำงานปกติ ชื่อและเลขบัตรจะถูกดึงมาใส่ในช่องให้อัตโนมัติครับ
